# EduCare Leads VSL — Voiceover Script (ElevenLabs-ready)

Generate **one clip per scene** and name each file exactly as shown, then drop them into
`public/vo/` (overwriting the scratch files). Then run:

```bash
npm run vo:measure   # re-measures durations from your new audio
npm run vsl:render   # re-renders out/educare-vsl.mp4 in sync
```

**Recommended ElevenLabs settings**
- Voice: a warm, confident, trustworthy narrator (not hypey) — e.g. *Brian*, *Adam*, or *Rachel*.
- Model: **Eleven Multilingual v2** (best quality) or **Turbo v2.5** (faster).
- Stability ~50% · Similarity ~75% · Style 0–15% · Speed ~0.95–1.0.
- Export: **MP3, 44.1 kHz**. Keep the `— em dashes` and line breaks; they help pacing.

> Numbers below are written out where pronunciation matters. ElevenLabs also reads
> "$14.10", "90 days", etc. correctly if you prefer digits — your call.
